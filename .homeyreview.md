# Review context for Omnik

Context for `homey app review`. Keep it factual and short.

## What the app is

A community app for Omnik solar inverters. It talks to the inverter's WiFi module on the local network only: the binary protocol on TCP port 8899, or the `/js/status.js` page over HTTP when the binary protocol isn't available. No cloud account is needed. It is for owners of Omnik inverters (the brand is no longer active, so there is no official app or cloud API to use instead).

## Choices a reviewer might question

- **Permissions:** none.
- **MAC discovery not linked to the driver:** the Omnik WiFi modules don't announce themselves (no mDNS or SSDP), so the app uses a MAC discovery strategy. It is read with `homey.discovery.getStrategy()` instead of being linked to the driver, because a linked strategy lets Homey manage availability and the module switches off every night while the device must stay available. Entering the IP by hand stays possible.
- **Device stays available when the inverter is unreachable:** by default an unreachable inverter is reported as 0 W instead of unavailable, because the inverter and its WiFi module switch off every night. Users can choose "Mark unavailable" in the device settings.
- **App settings page:** a diagnostic report tool to debug pairing problems. It only runs probes against the user's own inverter.
- **Other apps for the same brand:** none known.

## Unofficial

This is a community app. It is not affiliated with or endorsed by Omnik.
